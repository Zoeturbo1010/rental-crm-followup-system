# 客户跟进系统

一套面向租房平台团队的中文 CRM 高保真前端原型，使用模拟数据完整演示「平台进线 → 询问需求 → 加企微 → 推荐房源 → 预约看房 → 看房回访 → 成交结算」主流程。本作品集版本暂不纳入“不加 V”分支，重点展示加企微后的跟进提效与跨模块联动。

## 已实现页面

- 工作台：今日待办、指标卡、转化概览、看房日程与团队动态
- 客户管理：手动新增客户、需求档案、业务标签与看板/列表切换
- 跟进工作台：统一待办队列、跟进结果、下次提醒及自动流转
- 看房管理：从跟进预约进入日程，完成带看后自动生成回访任务
- 成交管理：从客户/看房记录创建成交，回写客户状态与佣金结算
- 数据分析：转化漏斗、转化率、趋势和流失原因

## 运行

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

然后打开终端显示的本地地址（默认是 `http://localhost:3000`）。

## 交互说明

- 点击左侧导航切换页面；所有页面共享同一份浏览器本地演示数据。
- 在“客户管理”点击“新增客户”，填写初始标签和下次跟进时间，客户会立即进入“跟进工作台”和提醒队列。
- 在“跟进工作台”保存跟进结果，会同步客户阶段、业务标签、详情时间线和下次提醒；选择“待预约/安排带看”可继续进入预约页。
- 预约保存后进入“看房管理”；完成看房会将客户转为“已看房·待推荐”，并生成“待回访”任务。
- 在客户详情点击“推荐房源”“预约看房”或“创建成交”，对应动作会回写客户、看房和成交模块。
- 业务标签支持：高紧急、高意向、客户未回复、暂无需求、半月后入住、没有合适房源、预算不匹配、已加企微、仅浏览用户、已收藏用户、房子不合适、二次推荐、待回访、待预约等。
- 所有数据为前端模拟数据，仅保存在当前浏览器，不会写入真实业务系统。
