# 住客邦 CRM 前端原型

一套面向租房平台团队的中文 CRM 高保真前端原型，使用模拟数据展示从 IM 进线、客户跟进、带看到成交结算的核心流程。

## 已实现页面

- 工作台：今日待办、指标卡、转化概览、看房日程与团队动态
- 客户跟进看板：按状态分列的客户卡片、状态筛选、看板/列表切换、客户详情抽屉
- 看房管理：预约日程、待确认提醒及带看信息
- 成交管理：成交记录、佣金与结算状态、新建/编辑成交表单
- 数据分析：转化漏斗、转化率、趋势和流失原因

## 运行

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

然后打开终端显示的本地地址（默认是 `http://localhost:3000`）。

## 交互说明

- 点击左侧导航切换页面。
- 点击客户卡片、待办或看房列表中的客户，可打开详情抽屉。
- 看板支持状态筛选以及看板/列表视图切换。
- 点击“新建成交”或成交表中的“编辑”，可打开分区成交表单。
- 表单保存、提醒、预约等操作均有模拟反馈，不会写入真实数据。

## 构建校验

```bash
npm run build
```
